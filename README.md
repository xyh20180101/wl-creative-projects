# WL Creative Projects

个人音乐 / 视频创作工程的公开归档仓库

目前收录 2015 年至今的多数翻唱曲 VSQX 工程，以及近期的 PV 工程，供学习、参考与二次创作使用。

## 仓库内容

- VSQX 工程：工程文件直接发布在本仓库中，命名格式为：`<声库>-<原曲名>(-<译名>)`
- PV 工程：由于文件很大，因此发布在 [GitHub Releases](../../releases) 中，命名格式为：`<软件>-<项目名>`
